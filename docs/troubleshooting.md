# Диагностика и восстановление

## Проверка загрузки

- В OpenCore выберите `Reset NVRAM`, затем загрузите macOS.
- В macOS проверьте `kextstat`/`kmutil showloaded` и убедитесь, что загружен `AirportItlwm`; `itlwm` в этой EFI отсутствует.
- Для звука проверьте наличие встроенных входа и выхода; в конфигурации используется `alcid=3`.

## Если не работает Wi‑Fi

1. Убедитесь, что загружен именно `AirportItlwm.kext` версии 2.3.0.
2. Если переносите старую EFI, удалите из неё `itlwm.kext` и не запускайте HeliPort для этого профиля.
3. Проверьте соответствие версии кекста версии macOS.
4. После изменений выполните Reset NVRAM.

## Если нужно перейти на Sequoia

Текущий репозиторий зафиксирован для Ventura. Для Sequoia нужен отдельный проверенный профиль: AirportItlwm 2.4.0, AMFIPass и root patch OCLP нельзя включать вслепую в эту конфигурацию.

## Восстановление EFI

Сначала сохраните текущий EFI-раздел. Затем скопируйте каталог `EFI` из репозитория на EFI-раздел и проверьте загрузку с резервной флешки. Не стирайте резервный загрузчик до полной проверки Wi‑Fi, звука, яркости и тачпада.
